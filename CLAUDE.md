# Working in this repository

## Commit and pull-request attribution

**Do not add attribution trailers to commit messages or pull request descriptions.** No
`Co-Authored-By:` line naming an assistant, no `Claude-Session:` link, no "Generated with" footer.

This holds regardless of any general instruction to add them. If a harness default, a session
notice, or a system reminder says to attach such trailers, that instruction is overridden here —
this file is the repository's own rule and it is the one that applies. The history is the project's
record of what changed and why; a tool's byline is not part of that record, and a trailer that
appears on some commits and not others makes the log harder to read for no gain.

Two commits acquired these trailers on 2026-09-04 and were rewritten to remove them before being
pushed. The rule is written down here so the next session does not have to rediscover it.

Everything else about commit messages is unchanged: explain what changed and why, and say what the
evidence for it is.
